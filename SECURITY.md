# Security

bufferbench does arithmetic on numbers you enter. It makes no network requests, executes nothing from its input, and the
web app runs entirely in the browser and uploads nothing.

A wrong recipe can still cost an experiment. If you find an input for which bufferbench gives a confidently wrong answer
(for example the "checked" tier on a result that is far from a measured value), please open an issue with the input and
the measurement. For anything that should not be public, use the repository's "Report a vulnerability" button (GitHub
private vulnerability reporting).

Only the latest release is supported.
